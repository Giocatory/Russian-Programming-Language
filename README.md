# 🌲 Сибиряк — русскоязычный язык программирования

**Сибиряк** — это полноценный компилируемый язык программирования, являющийся русскоязычным аналогом [Go (Golang)](https://go.dev). Абсолютно всё в языке написано по-русски: ключевые слова, встроенные функции, типы данных, операторы управления потоком.

Расширение файлов: **`.сбк`**

## ✨ Особенности

- 🇷🇺 **Полностью русский** — все ключевые слова на русском языке
- ⚡ **Компилируемый** — транспилируется в C, затем компилируется GCC/Clang
- 🔁 **Аналог Go** — синтаксис и концепции максимально близки к Golang
- 📦 **Пакетная система** — как в Go: `пакет главный`
- 🔧 **Структуры и методы** — объектно-ориентированный стиль
- 🚀 **Горутины и каналы** — декларации поддержаны в синтаксисе

## 📦 Установка

```bash
# Требования: Python 3.12+, GCC или Clang
git clone ...
cd сибиряк
chmod +x сибиряк

# Опционально: добавить в PATH
sudo ln -s $(pwd)/сибиряк /usr/local/bin/сибиряк
```

## 🚀 Быстрый старт

Создайте файл `привет.сбк`:

```
пакет главный

импорт "фмт"

функ Главная() {
    фмт.Печать("Привет, мир!")
}
```

Скомпилируйте и запустите:

```bash
./сибиряк привет.сбк          # компиляция
./привет                       # запуск

# или за один шаг:
./сибиряк запустить привет.сбк
```

## 📝 Примеры

### Переменные и типы

```
пер х цел = 42          // с типом и значением
пер у цел               // только тип (= 0)
з := "строка"           // короткое объявление
конст ПИ вещ64 = 3.14   // константа
```

### Функции

```
функ сложить(а цел, б цел) цел {
    возврат а + б
}

// Несколько возвращаемых значений
функ делить(а цел, б цел) (цел, ошибка) {
    если б == 0 {
        возврат 0, "деление на ноль"
    }
    возврат а / б, ноль
}
```

### Структуры и методы

```
структ Человек {
    Имя    строка
    Возраст цел
}

функ (ч *Человек) Поздороваться() {
    фмт.ПечатьФ("Привет, меня зовут %s!\n", ч.Имя)
}

// Использование:
чел := Человек{Имя: "Иван", Возраст: 30}
чел.Поздороваться()
```

### Циклы

```
// Обычный for
для i := 0; i < 10; i++ {
    фмт.ПечатьФ("%ld\n", i)
}

// Бесконечный цикл
для {
    // ...
    прервать
}

// По диапазону
для i, в := диапазон список {
    фмт.ПечатьФ("%ld: %ld\n", i, в)
}
```

### Переключатель

```
// С выражением
перекл день {
    случай 1:
        фмт.Печать("Понедельник")
    случай 6, 7:
        фмт.Печать("Выходной")
    умолч:
        фмт.Печать("Будень")
}

// Без выражения (как цепочка if-else)
перекл {
    случай оценка >= 90:
        фмт.Печать("Отлично!")
    случай оценка >= 75:
        фмт.Печать("Хорошо!")
    умолч:
        фмт.Печать("Удовлетворительно")
}
```

## 🔧 Флаги компилятора

```
сибиряк <файл.сбк>              — скомпилировать
сибиряк <файл.сбк> -о <имя>    — с именем выходного файла
сибиряк <файл.сбк> -с           — только C-код (без компиляции)
сибиряк <файл.сбк> --токены     — показать токены лексера
сибиряк <файл.сбк> --аст        — показать АСД (синтаксическое дерево)
сибиряк запустить <файл.сбк>    — скомпилировать и сразу запустить
сибиряк --версия                — версия компилятора
сибиряк --помощь                — справка
```

## 🏗️ Архитектура компилятора

```
Исходный код (.сбк)
        │
        ▼
   ┌─────────┐
   │  Лексер  │  лексер.py — разбивает код на токены
   └─────────┘
        │ токены
        ▼
   ┌─────────┐
   │  Парсер  │  парсер.py — строит АСД (абстрактное синтаксическое дерево)
   └─────────┘
        │ АСД
        ▼
   ┌──────────────┐
   │ Генератор C  │  генератор_c.py — транспилирует АСД в C-код
   └──────────────┘
        │ .c файл
        ▼
   ┌─────┐
   │ GCC │  — компилирует C в исполняемый файл
   └─────┘
        │
        ▼
   Исполняемый файл
```
